# Trees Shape

Guidance for the procedural L-system tree code.

The trees in this directory follow [ProceduralTrees](../.claude/reference/trees/ProceduralTrees.md#procedural-trees) and the documents it links to. Read the one for the stage you are changing before you change it. Keep derivation deterministic, keep every LOD built from the one skeleton, and never let a change of level swap geometry without the dithered cross-fade.
