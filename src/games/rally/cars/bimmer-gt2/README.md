# Bimmer GT2 (`bimmer_gt2`) - planned

A GT2-style E92 M3 race car for Gravel Rally (wide body, splitter, big wing), based on Tushar Singh's **CC BY** "E92 Barnfind"
Sketchfab model: the author's own design of an E92 M3 racing prototype styled after DTM, Group 5 and GT2 cars. **Not imported
yet**: the source file is stored and the licence checked; the import (simplify, parts, livery, physics) is open work in
[TODO.md](TODO.md). Not in the game or `release.ts` yet.
