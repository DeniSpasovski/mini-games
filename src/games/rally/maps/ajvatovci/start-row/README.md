# Ajvatovci start row

The first ~500 m of the Ajvatovci stage: the industrial street beside the A2 motorway. The placeholder boxes there are
replaced by hand-modelled lots: buildings with real window and door openings, yards, fences, gates, kerbs, sidewalks,
power poles, trees and about 100 parked vehicles. Everything is re-modelled for the game (PBR materials, real
openings, buildings sheared onto graded ground), and the street is a physical part of the track: the car bounces off
kerbs and stops at fences.

![Start street](../screenshots/start-street.jpg)

```bash
npm run dev     # /games/rally/?map=ajvatovci&spawn=200
```

The layout is traced by eye from satellite imagery (no imagery shipped). Details, coordinate frame, budget and modelling choices: [`DETAILS.md`](DETAILS.md).
